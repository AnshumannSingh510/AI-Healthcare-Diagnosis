# API Reference

Base URL (local dev): `http://localhost:8000/api/v1`

Interactive OpenAPI docs are also auto-generated by FastAPI at
`http://localhost:8000/docs` once the backend is running.

All endpoints except `/auth/register` and `/auth/login` require a Bearer JWT:
```
Authorization: Bearer <access_token>
```

## Auth

| Method | Path | Description |
|---|---|---|
| POST | `/auth/register` | Create a user (`role`: patient/doctor/admin) |
| POST | `/auth/login` | Returns `{access_token, refresh_token}` |
| POST | `/auth/refresh` | Exchange a refresh token for a new token pair |
| GET | `/auth/me` | Current user's profile |

## X-ray & Prediction

| Method | Path | Description |
|---|---|---|
| POST | `/xray/upload` | Multipart upload; enqueues async inference |
| GET | `/xray/{id}/status` | Poll processing status (`uploaded/processing/completed/failed`) |
| POST | `/predict?xray_id=...` | Synchronous inference trigger (dev/testing) |
| GET | `/predictions/{id}` | Fetch a specific prediction, including heatmap path, severity, recommendations, AI explanation, and disclaimer |
| GET | `/patients/{id}/history` | All predictions for a patient, most recent first |

## Doctor Review

| Method | Path | Description |
|---|---|---|
| GET | `/doctors/{id}/patients` | List of patients assigned to this doctor |
| POST | `/doctors/predictions/{id}/review` | Add notes; optionally approve |

## Reports

| Method | Path | Description |
|---|---|---|
| POST | `/reports/{prediction_id}/generate?doctor_comment=...&approve=true` | Generates a PDF report |
| GET | `/reports/{id}` | Downloads the PDF (`application/pdf`) |

## Chatbot

| Method | Path | Description |
|---|---|---|
| POST | `/chat` | `{question}` → `{answer, disclaimer}`. Answer always ends with a "consult a physician" disclaimer. |
| GET | `/chat/{user_id}/history` | Past chat turns for a user |

## Permissions summary

- **Patient**: can upload X-rays, view their own history/predictions/reports, use the chatbot.
- **Doctor**: can view assigned patients, review/annotate their predictions, approve reports.
- **Admin**: full access across all resources.

Ownership is enforced per-route: a patient requesting another patient's
`/patients/{id}/history` receives `403 Forbidden`; a doctor reviewing a
patient not assigned to them receives `403 Forbidden`.
